# Raytac版・トラックボールの復帰確認

対象と動作仕様は[スリープと復帰](sleep-wake.md)を参照してください。すべて実機未実施の確認項目です。試験後に結果を記入します。

## 準備

1. CoreX右（Raytac R A14）とCornix純正左を使います。左にもCoreX用ファームが必要です。
2. 右・左に書き込んだファイル名とSHA-256、PCの機種・OS、USBハブの有無を記録します。既存のブートローダに合うファイルを選びます。
3. キー・クリック・スクロールが通常時に動くことを確認します。トラボはまずJ4のみ、次にJ3のみで試します。差し替えはUSBと電池の電源を切って行います。
4. メモ帳など、最初の1文字と連打の有無を確認できる画面を開きます。PC自身の自動スリープは、キーボードだけの試験中は無効にします。
5. 配列を1か所、感度を1段階変更して、復帰後の保持を確認できる状態にします。

J3・J4両方の同時利用を案内する場合は、最後に2個同時接続でも同じ確認をします。各ポート単独の成功だけで、同時接続も確認済みとはしません。

## 合格の基準

- 接続を維持した通常スリープでは、キーまたはボールの操作から1秒以内に反応することを実機の合格目標にします。これは測定済みの保証値ではありません。
- 最初のキー押下と解放が1回ずつ届き、押しっぱなし・連打・解除できないクリックが残らないことを確認します。ボールは動き出しで止まらず、続けて操作できることを確認します。
- 接続が切れた場合は、必要な復帰操作の後10秒以内の再接続を目標にします。PC側が接続可能な状態で測ります。届かなかった最初の入力を、再接続後にまとめて再生しないことも確認します。
- 通常の復帰でRESET、電源OFF/ON、登録の削除、ペアリングのやり直しが必要なら不合格です。
- PC自体を起こせない場合は、PC本体で復帰させます。PCが操作可能になってから10秒以内に入力が戻るかを別に判定し、PCを起こせたかどうかと混同しません。
- 復帰後もキーマップ、感度、左右の登録、PCの登録が残っていることを確認します。

| W15 | 30分以上放置してから右キー・左キー・ボールを試す | 長い放置後も復帰する | 未実施 |

## 不具合が出たときの記録

まずRESETせず、次を記録してください。

- USB／BLE、左右どちらのキーが反応するか、J3／J4のどちらに接続したか。
- PC自身は起きているか。OSにCornix TBが接続済みと表示されているか。
- 何分放置し、最初に何を操作したか。1回の操作で戻るか、動かし続けると何秒で戻るか。
- 左のキー、右のキー、ボールの順に試した結果。LEDの色と点滅の有無。
- ファームのファイル名とSHA-256。ログを取れる場合は、その時点のログ。

記録後にRESETで戻るかを確認します。RESETで戻ったことだけを、スリープ復帰の合格にはしません。
