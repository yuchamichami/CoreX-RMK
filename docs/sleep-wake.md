# スリープと復帰

対象は、CoreX右（Raytac R A14）＋CoreX用ファームを書き込んだCornix純正左です。ポインティングデバイスはPAW3222のトラックボールのみを扱います。J3・J4のどちらも使用できます。Minew版・トラックポイント・トラックパッドは今回の検証対象外です。

この文書は2026年10月30日の出荷候補に対する動作仕様です。実機の合否は別の[確認表](sleep-wake-test.md)に記録します。自動テストだけでは出荷可と判断しません。

## 普段の使い方

左右とPCが接続済みなら、5分間キーやボールを操作しないと省電力状態に入ります。左右どちらかのキーを押すか、ボールを動かすと戻ります。RESET、電源の入れ直し、ペアリングのやり直しは必要ありません。

キーを押し続けている間や、ボールを動かしている間は、無操作によるスリープに入りません。キーを離した後、最後の操作から5分を数えます。

省電力中もボールの動きとキーを検出します。接続済みの相手との通信は維持し、トラボの電源は切りません。トラボの読み直しや初期化で最初の動きを捨てない設計です。

## 状態ごとの戻し方

| 状態 | 操作 | 期待する結果 |
| --- | --- | --- |
| PCは起動中。左右とPCの接続を保ったまま5分以上放置 | 右のキーを1回押して離す | 最初のキー入力と解放が届く |
| 同上 | 左のキーを1回押して離す | 左からの最初のキー入力と解放が届く |
| 同上 | J3またはJ4のボールを動かす | 連続してカーソルが動く。クリックとスクロールも使える |
| PCとのBLE接続が切れて5分以内 | PCのBluetoothが利用可能になる | 選択中の接続先への再接続を試みる |
| PCとのBLE接続が切れ、接続待ちが5分で終了した後 | 右のキー、右につながった左のキー、またはボールを操作 | BLEの接続待ちを再開する。再接続後に入力できる |
| 左右の通信が切れた直後 | 左右を近づけて電源をONにする | 保存済みの左右への再接続を試みる |
| 左右の通信が切れたまま、左の接続待ちも5分で終了した後 | 左のキーを押して離す | 左が接続待ちを再開し、保存済みの右へ再接続する |
| USB接続先のPCがスリープ中 | キーまたはボールを操作 | PC側でUSBからの復帰が許可されていれば復帰を要求する |
| PCをPC本体の操作で復帰させた後 | キー・ボールを操作 | USBまたはBLEの接続が戻り、入力できる |

**左右が切れたまま左が待機を終了した場合は、左側のキー操作が必要です。右のボールだけでは、通信していない左を起こせません。** 右側の入力と、左側の再接続は分けて確認します。

接続を保ったままの省電力復帰では最初の入力を保持します。接続を失っている場合、再接続を始めるための最初のキー入力やボールの動きはPCへ届くとは限りません。再接続後に入力を確認してください。

## PCのスリープについて

キーボードの5分間の省電力と、PCのスリープは別です。PCが省電力を要求すると、キーボードが5分を待たずに省電力へ入る場合もあります。

キーやボールでPC自体を起こせるかは、OS・接続方法・USBハブ・復帰許可の設定に依存します。PCを起こせなかった場合でも、PC本体から復帰させた後に入力が戻ることを確認します。

## LEDと保存設定

通常のスリープ復帰に専用の成功点灯はありません。カーソルやキー入力が戻ることを確認します。青い点滅・緑の点灯は、明示的な左右登録の案内なので、通常の復帰では要求しません。

スリープ、復帰、再接続で、キーマップ・感度・左右の登録・PCの登録情報を消しません。通常の復帰で新しい相手のペアリングを始めることもありません。

省電力時の実測消費電流と、実際の復帰時間は未測定です。電池持ちの数値は、この仕様から推定して保証しません。
